# 05: Section 2 — what a markdown file is

**What to build:** The section that levels the room. A hub-and-spoke diagram with a single markdown file at its centre — carrying a small frontmatter block at its top, planted deliberately and left unexplained — with arrows out to the three things markdown files are used for: Context, Knowledge, and Instruction. The audience leaves knowing a markdown file is a text file with nothing mechanical underneath, and that what matters is how and when it is consumed.

The planted frontmatter block is decorative and deliberately unexplained; it is not the shared frontmatter component used later.
