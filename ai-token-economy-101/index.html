S7.1 · Tools & Tips

Two Levers for Context: Automate vs. Practice

You can't ignore the context economy. Reclaim headroom by automating the heavy lifting, and establish team practices for leaner, more effective prompts.

Automated

  • Headroom High ROI

    Automatic context summarization before limits are hit.

  • Retrieval-Augmented Tooling (RTK) High ROI

    Search and fetch only the necessary code chunks.

  • Caveman Methods Net-Negative

    Blindly dumping entire repositories into context destroys output quality.

Team Practices

  • Edit, Don't Restart

    Modify previous prompts instead of accumulating context linearly with "no, do this instead".

  • Session Hygiene

    Start fresh sessions for new tasks; avoid reusing bloated mega-threads.

  • Match Billing to Value

    Use smaller models for routine tasks to save your heavy-reasoning budget.
